# Alejandro Martín — Portfolio

**Tengo 18 años. Esto es lo que sé construir.**

Portfolio hecho a medida con Astro, React y Tailwind: sin plantillas, sin florituras. Tiene una vista para reclutadores (`/`) y otra para desarrolladores (`/dev`) con una terminal interactiva.

---

## Qué incluye

### Vista para reclutadores
Presentación, proyectos con su problema y su solución, stack, open source y contacto.

### Vista para desarrolladores
Una terminal interactiva con comandos para explorar el perfil, los proyectos y el stack.

### Proyectos
Los proyectos mantienen un orden manual. Los repositorios privados se muestran como confidenciales, con aviso de NDA.

### Open source
Pull requests mergeadas en otros proyectos, con título y enlaces a GitHub. Se sincronizan desde GitHub con un cron.

### Panel de administración
Panel con acceso por GitHub OAuth para gestionar proyectos, stack (lista agrupada manual), hoja de ruta y ajustes sin tocar el código.

### Todo basado en datos
Proyectos, stack, ambiciones, ajustes e identidad viven en JSON dentro de `public/data`. La interfaz solo los muestra.
